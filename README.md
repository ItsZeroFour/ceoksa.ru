# Credit Application Portal

A simple and responsive web application for submitting credit (loan) applications. Built with **React** (frontend) and **Node.js** (backend).

## ✨ Features

- Fill out and submit a credit application form
- Real-time form validation
- View application summary before submission
- RESTful backend API for handling requests
- Responsive design (works on mobile & desktop)

## 🛠️ Tech Stack

- **Frontend**: React, React Router, Axios, etc.
- **Backend**: Node.js, Express.js
- **Data**: MongoDB
- **Tools**: npm, ESLint, Prettier
